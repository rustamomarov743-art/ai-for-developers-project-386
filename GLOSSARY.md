# Календарь звонков

Сервис бронирования встреч с одним заранее заданным владельцем и гостевой записью без регистрации.

## Language

**Владелец**:
Единственный заранее заданный пользователь, который создаёт типы встреч и просматривает предстоящие встречи.

**Гость**:
Пользователь, который выбирает свободное время и бронирует встречу с владельцем без регистрации.
_Avoid_: клиент, посетитель

**Тип встречи**:
Заданный владельцем формат встречи с названием, описанием и произвольной длительностью.

**Бронирование**:
Создание встречи на выбранный гостем тип и интервал времени без регистрации и авторизации.
_Avoid_: запись, резервирование

**Доступность**:
Задаваемые владельцем повторяющиеся недельные интервалы и исключения для конкретных дат, в пределах которых гость может выбирать время встречи.

**Недельный шаблон**:
Повторяющаяся каждую неделю часть доступности, состоящая из интервалов для отдельных дней недели.

**Исключение доступности**:
Закрытый день или особые интервалы на конкретную дату, полностью заменяющие недельный шаблон этой даты.
_Avoid_: переопределение, особый день

**Слот**:
Возможный интервал бронирования выбранного типа встречи, сформированный с учётом доступности, существующих бронирований и близости текущего момента.

**Встреча**:
Интервал времени, забронированный гостем с владельцем по выбранному типу встречи.

**Предстоящая встреча**:
Забронированная гостем встреча, которая ещё не закончилась.

**Завершённая встреча**:
Встреча, которая не была отменена и интервал которой закончился.

**Отменённая встреча**:
Встреча, которую владелец отменил до её начала.

**Календарь владельца**:
Месячное представление предстоящих встреч, предназначенное только для просмотра расписания.

**Главная страница**:
Стартовая страница сервиса, ориентированная на гостя и содержащая переходы к бронированию и сценарию владельца.
_Avoid_: разводящая страница, лендинг
