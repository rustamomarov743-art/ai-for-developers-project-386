## Стек

- java 25
- Spring Boot 4.2.x
- React, TypeScript и Vite
- API-контракт: TypeSpec → OpenAPI (`api/`)
- Клиентский SDK: `@hey-api/openapi-ts` с `@hey-api/client-fetch` и `@hey-api/sdk`; плоские функции, результат генерации — `frontend/src/api/generated/`

Версия генератора клиента будет зафиксирована точно, без диапазона. Сгенерированные файлы не редактируются вручную.

## Сценарий

1. Путь владельца 
 - создаёт тип встречи;
 - указывает название, описание и длительность;
 - просматривает общий список предстоящих встреч.

2. Путь гостя
 - открывает публичную страницу владельца
 - выбирает тип встречи; 
 - открывает календарь на ближайшие 14 календарных дней; 
 - выбирает свободный слот; 
 - указывает имя и email;
 - записывается и получает подтверждение.

3. Результат бронирования 
 - встреча появляется в списке владельца;
 - занятое время больше недоступно;
 - запрещены любые пересечения интервалов, даже между разными типами встреч; 
 - следующая встреча может начинаться ровно в момент окончания предыдущей; 
 - правило должно соблюдаться и при одновременных запросах.

4. Ограничения
 - владелец только один и задан заранее; 
 - регистрации и авторизации нет;
 - внешних календарей и уведомлений нет.
